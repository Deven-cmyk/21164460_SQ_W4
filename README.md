# Getting Over It: The Vessel Choice

## Project Description

This project is a p5.js Choose Your Own Adventure game inspired by "Getting Over It with Bennett Foddy". The player guides Diogenes through a branching narrative by selecting different combinations of vessels and climbing tools to help him conquer the mountain.

The game features 15 completely unique scene files and 8 different endings. All visuals, including the character, detailed mountain biome, and animated gradient sky, are procedurally drawn using core p5.js shape functions without the use of external image assets.

## Setup and Interaction Instructions

To run the sketch locally, open `index.html` in Google Chrome using Live Server (Right-click `index.html` in Visual Studio Code and select **Open with Live Server**).

**Controls:**

- **Mouse Hover** → Highlights the interactive buttons
- **Left Mouse Click** → Triggers background music and confirms your choice
- **R** → Restarts the game (Only active on ending screens)

**Objective:**

- Read the narrative prompts on the screen.
- Choose a vessel (Cauldron, Metal Barrel, Wood Barrel, or Ceramic Bowl) and pair it with a tool.
- Try to find the "Canon Ending" (The True Ascent) without shattering your vessel or getting stuck.
- Reach all 8 unique endings.

**Opening the Chrome Console (for debugging):**

- **Windows:** Press `F12` or `Ctrl + Shift + J`, then click the **Console** tab
- **Mac:** Press `Cmd + Option + J`
